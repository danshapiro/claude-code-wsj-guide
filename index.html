Getting Started

Three steps to your AI newsroom

You'll need a personal laptop you can install software on. The whole process takes about 10 minutes.

1

Subscribe to Claude Pro

Go to claude.ai and sign up for the Claude Pro plan — it's $20/month and gives you access to Claude Code, Anthropic's most capable models, and priority access to new features.

$ 20 /month

Dow Jones policy note: Check with your IT/compliance team about installing third-party tools on work devices. You may want to use a personal laptop for this. Claude processes prompts on Anthropic's servers — be mindful about entering sensitive unpublished reporting details.

2

Install Claude Code

Open your terminal and run the installer. On macOS or Linux, it's a single command. No coding experience required — if you can copy-paste into a terminal, you're good.

# macOS / Linux — one command, no dependencies $ curl -fsSL https://cli.claude.ai/install.sh | sh # Or if you have Node.js (alternative method) $ npm install -g @anthropic-ai/claude-code

Not sure how to open a terminal? On Mac, search for "Terminal" in Spotlight (⌘ + Space). Use claude.ai (the chat interface) to walk you through it — just ask!

3

Authenticate & Go

Run claude in your terminal. A browser window will open for you to log in with your Anthropic account. Once authenticated, you're ready — just start typing what you want to do.
